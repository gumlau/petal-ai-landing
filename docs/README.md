## 建议阅读顺序

### 第一阶段：理解产品定位（1-2 天）

1. **[产品愿景](product-strategy/product-vision.md)** - 首先理解 "心智像水" 愿景
2. **[问题定义](user-research/problem-definition.md)** - 明确解决的核心问题
3. **[北极星指标](product-strategy/north-star-metrics.md)** - 确定追踪的核心指标

### 第二阶段：验证市场机会（2-3 天）

4. **[创业想法验证](product-strategy/startup-ideation.md)** - 评估市场是否值得进入
5. **[竞争分析](product-strategy/competitive-analysis.md)** - 了解竞争格局
6. **[PMF 测量](product-strategy/measuring-pmf.md)** - 设定验证里程碑

### 第三阶段：规划执行策略（2-3 天）

7. **[路线图优先级](product-strategy/roadmap-prioritization.md)** - 决定先做什么
8. **[OKR 与目标设定](product-strategy/okrs-and-goals.md)** - 设定具体目标
9. **[范围控制](execution/scoping-and-cutting.md)** - 学会说 "不"

### 第四阶段：深化产品思维（持续学习）

10. **[产品品味](product-strategy/product-taste.md)** - 培养设计直觉
11. **[行为产品设计](product-strategy/behavioral-design.md)** - 理解用户心理
12. **[逆向工作法](product-strategy/working-backwards.md)** - 从终态反推策略

### 第五阶段：建立用户研究能力（按需）

13. **[用户访谈](user-research/user-interviews.md)** - 掌握访谈技巧
14. **[调研设计](user-research/survey-design.md)** - 设计有效问卷
15. **[用户反馈分析](user-research/feedback-analysis.md)** - 建立反馈系统
16. **[可用性测试](user-research/usability-testing.md)** - 验证产品可用性

### 第六阶段：执行与发布（按需）

17. **[PRD 写作指南](execution/writing-prds.md)** - 写好需求文档
18. **[规格与设计](execution/specs-and-designs.md)** - 设计规格指南
19. **[时间管理](execution/timeline-management.md)** - 管理开发时间
20. **[产品发布](execution/shipping-products.md)** - 规划发布策略
21. **[产品运营](execution/product-operations.md)** - 建立运营体系

### 决策参考（随时查阅）

- **[产品转型/Pivot](product-strategy/startup-pivoting.md)** - 当需要考虑方向调整时

## 如何使用这些文档

### 作为决策参考

当面临产品决策时，查阅相关文档中的**关键洞察**和**行动建议**章节。

### 作为学习资源

每个文档的**核心原则**章节总结了该领域的方法论精华，**参考资料**章节提供进一步学习的链接。

### 作为工作模板

文档中提供的模板（如 OKR 模板、访谈问题模板、检查清单等）可以直接应用于日常工作。
