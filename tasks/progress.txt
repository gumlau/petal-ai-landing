## Codebase Patterns
- Use `cn()` from `@/lib/utils` for className merging (clsx + tailwind-merge)
- Custom theme colors are defined in globals.css using CSS variables
- Primary color is emerald (#10b981), configurable via --primary variable
- Font is Inter, loaded via next/font/google
- Project uses Next.js 14+ with App Router and TypeScript strict mode
- All components should go in src/components/
- Utility functions in src/lib/
- Constants in src/constants/
- Use "use client" directive for interactive components (useState, useEffect, onClick, etc.)
- Tailwind v4 opacity: use bg-color/80 syntax (not bg-opacity-80)
